## Chosen approach and rollback

Use an additive builder with `--layout original|grid24`. Original mode copies
the sealed v17 ROM byte for byte; grid24 emits a separate diagnostic filename.
No154parent source file is edited. A local Git backup tag identifies the
pre-experiment checkout. Retain v17 release/assets and every prior sealed root.
Runtime toggling is unnecessary: loading v17 or choosing original build mode
rolls the presentation back without carrying incompatible page/cache history.
