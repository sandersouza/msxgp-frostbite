# v0.0.29 — aligned RETROWORKS wordmark

RETROWORKS now ends at the right edge of the playfield, using angular,
lightly slanted uppercase lettering inspired by the original Atari presentation.
It has the same seven-pixel height and baseline as Activision. The hyphen is
removed. Both wordmarks remain aligned through the original one-pixel vertical
footer shift. Activision's original graphic, gameplay, controls, colors and PSG
are preserved, including the v28 edge corrections.

[Play in WebMSX](https://webmsx.org/?M=MSX1A&P=RAMNORMAL,NODISK&ROM=https%3A%2F%2Fgithub.com%2Fsandersouza%2Fmsxgp-frostbite%2Freleases%2Fdownload%2Fv0.0.29-aligned-credit-diagnostic%2Ffrostbite-0.0.29-aligned-credit-diagnostic.rom&ROM_FORMAT=ASCII16).
