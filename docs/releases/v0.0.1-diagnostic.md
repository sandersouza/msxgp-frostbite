# v0.0.1-diagnostic — first MSX1 development cartridge

This is a **hardware/development diagnostic**, with no Frostbite gameplay yet.
It checks the cartridge entry point, SCREEN 1 text, BIOS interrupts, controls
and the built-in PSG. It contains no original Atari ROM, sprites or game code.

## Download and setup

- ROM: `{{ROM_FILENAME}}`, 16,384 bytes, plain 16 KiB cartridge, **Normal/no mapper**.
- Target: standard-speed MSX1, **64 KiB RAM / 16 KiB VRAM**, TMS9918-family VDP,
  built-in PSG. No RAM expansion, turbo, disk or extra sound hardware required.
- Source commit: `{{SOURCE_COMMIT}}`.
- ROM SHA-256: `{{ROM_SHA256}}`.
- Attached build.json, smoke.json and SHA256SUMS identify the tested bytes.

In openMSX, select **C-BIOS_MSX1**, insert the ROM as a Normal cartridge and
reset/power on. Keep standard Z80 speed and disable optional expansions/turbo.
On real MSX1, load it through a cartridge/flash-cartridge capable of plain
16 KiB ROMs; no mapper or expanded host RAM is needed. Use the normal MSX BIOS.

## What works and what was checked

The blue diagnostic screen shows the title/version, a hexadecimal heartbeat,
direction 0–8 and fire 0/1. The heartbeat should keep advancing. Cursor keys or
joystick 1 change direction; SPACE or joystick-1 fire enables a steady PSG tone
while held and silence on release.

Pinned assemblers and dependencies were prepared and repeated from a clean
source clone on macOS arm64. Repeated builds produced identical ROM bytes.
Automated openMSX checks passed on an isolated 64 KiB C-BIOS MSX1/TMS9918A
profile at 3,579,545 Hz: enabled display/title/readouts, advancing interrupts,
UP/release, SPACE/held edge/release and PSG period/volume. A deliberately
booting ROM with a disabled heartbeat was correctly rejected. A rendered
screenshot was inspected separately from the accelerated headless checks.

No gameplay, Atari-mechanics equivalence, complete-game timing, human listening
or physical MSX acceptance is claimed. Intel macOS is prepared in the setup
script but has not been exercised; automated video validation here is NTSC.

## Tests requested from the human

1. Boot on unexpanded MSX1/openMSX with the setup above. Expect the blue
   **FROSTBITE MSX1 / DIAGNOSTIC v0.0.1** screen, readable text and an advancing
   heartbeat. Leave it running for at least one minute; report freezes or damage.
2. Press/release UP, RIGHT, DOWN and LEFT. Expect direction 1,3,5,7 respectively,
   then 0 on release. Try diagonals; report stuck or incorrect values. Repeat
   with joystick 1 if available.
3. Hold SPACE, then release. Expect FIRE=1 and a steady tone while held,
   FIRE=0 and silence after release. Repeat with joystick-1 fire. Report missing
   sound, persistent sound, glitches or input differences. Listening remains pending.
4. Reset and repeat. If available, try a physical PAL and NTSC MSX1 at normal
   speed; the heartbeat may advance at different rates but must continue.

Please return machine/emulator model/version, PAL/NTSC, RAM, cartridge/loading
method and mapper setting, controller used, pass/fail per step and a short
photo/video/audio sample of any defect. A successful diagnostic is not gameplay
acceptance; no lengthy play session is requested for this version.
