# v0.0.9-performance-preview — equivalent rendering optimizations

This diagnostic reduces repeated font-mask work, selects fixed actor roles
directly, and uses a faster exact igloo composition for backgrounds certified
by all eight pattern/color rows. Other backgrounds retain the general merge.
The complete graphics, actors, original update sequence and PSG integration
remain present. The landed-ice contrast correction from 0.0.8 is retained.

**Original-speed gameplay is still unfinished.** This is a limited performance,
visual and sound regression preview. It does not qualify full real-time gameplay
or approve original rhythm, difficulty and collision timing. Issue 14 stays open.

## Human tests requested

Use the same machine/emulator configuration and initial display view as 0.0.8,
at normal speed. F3/F4 alternate diagnostic views are not newly qualified.

1. Tap **F1** to start. Use cursor keys or a joystick to move and jump between
   rows. Land on several white rows: they should turn light blue and remain
   visible against the darker sea, including near both screen edges.
2. On a contacted blue row, press and release **Space/joystick fire** to reverse
   it. Repeat after another fresh press. Check for missing ice, corrupted tiles
   or player/objects disappearing. Normal source row resets remain expected.
3. Build several igloo blocks and watch the score, temperature and lives. They
   should remain intact while changing, with no new flashing or stale digits.
4. Compare 0.0.8 and 0.0.9 in the same setup and actions. Report whether movement
   feels smoother and where slowdown remains strongest. A 20–30 second video
   with sound, several landed rows and an igloo change is especially useful.
   This subjective comparison is feedback, not original-cadence acceptance.
5. Check sounds during landing, row reversal and losing a life. Report missing,
   stuck or newly distorted sound. Test both joystick ports if available.
   **F1** resets and **F2** selects the original variation.

Please include version, machine/VDP, NTSC/PAL, emulator/version or physical
cartridge/loader, variation, controls and exact actions in the report.
