## Tests expected from the human

1. Open WebMSX above, or load as ASCII16 on standard-speed MSX1 at100%,64KiB RAM,
   PSG only. Tap/click to enable audio. F1 starts/resets; arrows move/jump,
   Space/fire performs the original action. Mobile virtual controls or keyboard/
   joystick may be used; mobile controls have not been physically verified here.
2. Compare v19/v20. Jump through all four ice rows while steering continuously
   left/right. Check unchanged artwork/colors/contact and whether motion looks
   smoother. Land and immediately jump again; report missed-looking landings.
3. Turn ice blue, reverse rows and wait for wraparound repeatedly. Expect no
   stale white/blue tiles, flashes, holes, footer corruption or stationary edge
   fragments. Complete/enter the igloo and start the following stage.
4. Continue to moving bears and dense enemies if practical. Slower presentation
   there is a known remaining bottleneck; report stage and TV mode.
5. Send a short recording with sound, ROM version, MSX/emulator model, NTSC/PAL
   and actions. Mark any hitch/contact/color problem. This test need not block
   the next automated investigation while you are away.
