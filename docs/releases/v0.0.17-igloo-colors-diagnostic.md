# v0.0.17 — Igloo color-only diagnostic

This diagnostic continues v0.0.16. An unchanged igloo tile reuses its patterns;
certified background-color changes write only the eight color bytes. Changed
shapes, cold tiles and uncertified backgrounds still use the complete renderer.
No new RAM/VRAM is allocated. Graphics, original simulation, input and ordered
PSG behavior remain exact in the bounded automated checks.

## Measured result against v0.0.16

| Whole-game active route | v0.0.16 | v0.0.17 |
|---|---:|---:|
| NTSC complete pictures/s | 25.4519 | 25.9009 (+1.76%) |
| PAL complete pictures/s | 22.9176 | 23.1226 (+0.89%) |
| NTSC foreground mean, CPU cycles | 70,935 | 69,756 |
| PAL foreground mean, CPU cycles | 75,403 | 74,907 |
| PAL P95 / longest picture gap, ms | 79.713 / 99.683 | 59.843 / 79.780 |
| NTSC grounded landings shown /26 | 15 | 14 |
| PAL grounded landings shown /26 | 12 | 13 |

The igloo's observed cycles per active picture decrease 13.29% NTSC / 12.15%
PAL. Whole-foreground means decrease 1.66% / 0.66%; the sampled picture
populations differ, so stage differences are not paired component CPU savings.
The original simulation clock remains approximately 59.92 steps/s.

**Limitations:** motion remains uneven; stable 30 fps and original fluidity are
not achieved. NTSC no longer presents one grounded landing (arc 21, source step
1672); its first post-landing picture age rises from two to three source steps,
and P95 over all 26 landings rises from five to six steps. Endpoint-Y coverage
remains 21/26. PAL grounded coverage rises to 13/26 and endpoint coverage to
20/26; one previously missed pose run is now shown. The worst observed igloo
call increases from 25,025 to 27,389 cycles on the necessary full path. Original
state/contact rules remain identical; these are presentation limitations.

## Automated checks

- 569 host tests; independent clean rebuild and 917,504 constructor comparisons.
- 2,115 source scenes, 1,920 density scenes, 54 header cases and 10,560 clipping cases.
- 2,115 audio intervals, with 3,499 source / 2,472 physical PSG writes in exact order.
- Natural NTSC/expanded-RAM PAL: 4,507 original CPU/all-RAM checkpoints and
  2,510 coherent pictures; exact pixels/owners, no active-page corruption,
  no late VBlanks or canonical source writes. Clean final runs reproduce all
  five measured buffers byte for byte.
- Nine hardware-interrupt boundaries in each mode, rejected AF2 corruption,
  and two extra real interrupts inside the new bank-119 color stream. Directed
  interrupt runs are excluded from performance figures.
- Exact-source push and PR CI pass. The workbook preserves all 29 earlier
  sheets and adds AD Igloo; formulas and exported contents were independently
  audited and six regions visually checked. Native Excel was not exercised.

These are automated emulator/host checks. Human visual/audio/controller,
all-level, original-fluidity and physical MSX1 acceptance remain pending.

## Tests requested from the human

1. Compare v0.0.16 and this ROM using the same MSX1 profile at 100% speed and
   ASCII16 mapper. Test NTSC and PAL separately if possible. Tap F1 to start;
   arrows/joystick move and jump, Space/fire performs the original action.
2. Build the igloo while the upper band cycles colors. Expect identical block
   shapes and gray foreground, with no flashing, missing blocks or stale
   background colors. Reverse an ice row and continue building to exercise
   changed colors and igloo progress.
3. Repeat up/down jumps, jump immediately after landing, and steer horizontally
   during jumps. Compare skipped poses and landing feedback against v0.0.16.
   The gain is small; do not expect fully smooth motion from this release.
4. Send a short recording with audio, NTSC/PAL profile, emulator/version or
   physical model, and whether graphics, controls, landing feedback or sound
   differ. Identify the moment of any glitch or hitch.
