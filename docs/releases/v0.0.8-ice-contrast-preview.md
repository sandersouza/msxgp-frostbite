# v0.0.8-ice-contrast-preview — landed ice remains visible

This diagnostic addresses the owner's0.0.7 feedback: after landing, ice turned
the same blue as the sea and disappeared. Original source colors98 and90 were
both mapped to TMS dark blue4. The updated mapping keeps the sea dark blue4
and uses light blue5 for landed ice. Source RAM, collisions, scoring and audio
logic are unchanged. Other original elements using the same98 source color also
use the corrected light blue. This is a presentation adaptation, not identical
Atari/TMS analog color.

**The original-speed goal is still unfinished.** This is a contrast-regression
preview, not a claim that slowdown, tearing or full gameplay cadence is fixed.
More ice remains visible, so its full rendering cost is measured again rather
than hidden by the old color collision. Issue14 remains open.

used for0.0.7 when possible. F3/F4 diagnostic views are not newly qualified here.
