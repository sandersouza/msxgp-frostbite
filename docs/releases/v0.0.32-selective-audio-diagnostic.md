# v0.0.32 — Selective death and bear audio diagnostic

Only drowning, freezing and effective bear pursuit are louder. All original
audio writes and raw latches remain unchanged; four source-store sites select
a presentation-only PSG gain. Other effects, silence, tone/noise parameters,
source envelopes, duration, gameplay and graphics are preserved by the checks
below. v0.0.31 remains available unchanged for comparison and rollback.

**Gain precision:** the requested +25% amplitude is +1.94 dB. Static PSG volume
steps cannot represent it exactly. These effects use level 4; this diagnostic
selects level 5, the nearest available level, approximately **+41.4% amplitude
(+3.01 dB)** in the pinned openMSX AY/YM model. No global gain, dithering or
extra sound channel is used. Actual analog output depends on the MSX hardware.
This is a listening candidate, not a claim of exact 25% or perceptual acceptance.

## Tests expected from the human

Keep the same emulator/machine, audio mixer volume and speed when comparing
v0.0.31 with this release. Disable turbo and emulator audio normalization.
Load the cartridge as **Normal** on MSX1 with 64 KiB RAM/16 KiB VRAM, at 100% speed.
Use **F1** to start/reset, arrows to move/jump and Space/joystick fire.

1. **Drowning:** jump into a gap between ice blocks and let Bailey drown.
   Expect a louder effect, with the same pitch, rhythm and duration as v31.
2. **Freezing:** start the first game and remain safely on shore until the
   temperature expires. Expect a louder freezing effect and unchanged death,
   life-loss and restart behavior.
3. **Bear pursuit:** select game 3 using F2 (release between presses), then F1.
   Stay grounded on shore and allow the bear to approach/push Bailey. Compare
   the chase sound; expect more volume without changing its modulation/rhythm.
4. **Other sounds and silence:** jump, activate ice, collect a fish and reset.
   Expect their previous volumes, no stuck sound, and no gain carried into the
   next unrelated effect. Watch movement and graphics for regressions.
5. **DOS/BASIC, if available:** run `FROSTBIT.COM` from MSX-DOS; or keep all
   three BASIC files together and run `RUN"FROSTBIT.BAS"`. Expect the same audio
   change. Machine RESET exits; returning to DOS/BASIC is not implemented.

Report which of the three sounds is comfortable, still quiet or too loud;
include format, emulator/MSX model and NTSC/PAL. A short video with sound is
especially useful for any changed pitch, stuck noise or timing issue.
