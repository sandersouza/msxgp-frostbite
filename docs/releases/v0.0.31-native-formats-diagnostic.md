## Tests expected from the human

1. **Cartridge:** load the ROM as **Normal**,100% MSX1 speed,64 KiB RAM,
   16 KiB VRAM. Let it cold-boot, then use **F1** to start/reset, arrows to
   move/jump, and Space/joystick fire. Expect the accepted graphics, colors,
   lowercase credit and controls. Report a blank screen or startup failure.
2. **DOS:** place `FROSTBIT.COM` on a bootable MSX-DOS1 disk and run `FROSTBIT`.
   Expect the same game, controls and sound. No other game file is required.
3. **BASIC:** keep `FROSTBIT.BAS`, `FROSTBIT.BIN` and **FBGFX.BIN** together on
   the disk. Run `RUN"FROSTBIT.BAS"`. The launcher uses `CLEAR 200,&H87FF`,
   `BLOAD"FBGFX.BIN",S` and `BLOAD"FROSTBIT.BIN",R`. The companion is required.
   Expect the same game after loading. Successful takeover uses the full RAM;
   **machine RESET** exits/reboots. Return to DOS/BASIC is not implemented.
4. Play several minutes in each available format. Jump between ice rows,
   change direction during jumps, land repeatedly, finish an igloo, fall into
   water and encounter the bear. Expect original contacts, progression,
   controls, player colors and sound events, with no corrupt or stale tiles.
5. Repeat left-edge dragging and watch enemies enter at the right. Expect
   gradual clipping at the visible boundary and no premature wrapped fragment.
   Compare motion with the unchanged v30, especially landings and the bear.
6. Send the format, emulator or physical MSX model, NTSC/PAL, startup result,
   and a short video with sound if cadence, loading, graphics or audio differ.
   State whether the remaining cadence loss is noticeable during play.
