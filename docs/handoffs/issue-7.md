## Decisions retained for successors

- One exclusive shared-checkout writer follows the approved workflow; cost if
  wrong: isolation depends on ownership coordination rather than worktrees.
- Stella is primary because all4 variations/both controllers/console are exposed.
  ALE's Python second act argument is paddle strength; cost: ALE cannot certify
  full two-player/cross-backend equality.
- Control the RIOT timer preset127, host PRNG seed1 and initial debug counter
  before execution, then compare every generated byte unmasked. Stella randomizes
  RIOT despite other randomization flags; cost: this is not an exhaustive physical
  power-on distribution.
- F019 passages retain actual frame/cycle counters, not an assumed raster frame.
  Cost: future variable dispatch may require more alignment boundaries.
- Reject a preseeded output slot unless CPU progress is fresh. Cost: monotonic
  cycle assumptions apply to bounded non-system-reset intervals only.
- Keep the logical projection separate from source hardware state. Cost: the
  conservative all-RAM/register mapping may need a reviewed representation
  contract later; no silent masks.
- Reject the invented two-direction bear patrol predicate. The source pursues
  Bailey then stops at the edge; cost: one blocked approach does not certify all
  bear routes. Walking reaches X10 and fails; jumping naturally reaches X09.
- Reset release80 supersedes provisional16, which left original E7 input delay
  active. Cost if wrong: a pin-only early trace would overstate gameplay coverage;
  accepted final captures exercise active input.
- C7=1 selected-player tests are explicitly controlled one-byte fixtures. Cost:
  they do not establish natural death/record swap progression.
